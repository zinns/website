# Zinns Website

This repository is the blank baseline for the Zinns website.

The current state is intentionally small:

- latest stable Next.js stack
- `pnpm` package migration
- no automations
- no GitHub workflows
- minimal placeholder UI until the design direction is defined

## Stack

- Next.js `16.2.6`
- React `19.2.6`
- Tailwind CSS `4.3.0`
- TypeScript `6.0.3`
- pnpm `11.1.3`

## Getting Started

Install dependencies:

```bash
corepack pnpm install
```

Start the development server:

```bash
corepack pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available Scripts

```bash
corepack pnpm dev
corepack pnpm lint
corepack pnpm typecheck
corepack pnpm build
corepack pnpm check
```
