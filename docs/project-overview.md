# Project Overview

Zinns is a company website for a creative technology lab.

The positioning for this version is:

```text
We build customized digital tools and help people increase their abilities.
```

## Current Website

The first version is intentionally small:

- One public route: `/`
- English and Spanish content
- Company overview
- Project preview with in-progress work
- Education plans for 1:1 web and mobile development mentoring
- Placeholder reviews
- Company brief
- Placeholder people section
- Common stack
- Next capability areas
- Contact form and direct email link

The UI presents project work as active summaries and explicitly marks placeholder reviews and
placeholder people so temporary content is not confused with customer testimonials or team profiles.

## Future Site Map

The larger map is useful for planning, but these routes are not implemented yet:

- `/projects`: current, past, and incoming work
- `/education`: mentoring, courses, workshops, and learning paths
- `/company`: history, team, values, stack, and operating style
- `/integrations`: Python, data science, cybersecurity, content, and automation capabilities
- `/contact`: dedicated contact page
- `/dashboard`: future authenticated user dashboard
- `/automations`: future internal or authenticated automation surface

## Current Non-Goals

- No database schema
- No authentication
- No dashboard
- No CMS
- No automation backend
- No real customer testimonials until approved
